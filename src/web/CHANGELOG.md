## 1.7.1
- In MAXINE! Studio, typing a font code sets the master id to match, which you can still change afterwards
- Removed the warning about font codes below 9000
- The desktop app sends Video and Key as two NDI sources, MAXINE! Fill and MAXINE! Matte. The browser version doesn't have this.
- The desktop app triggers the MAXINE!'s eight GPI inputs from a button or over UDP, and each one presses F1–F8 as on a real unit
- The web page links the BVE-9100 emulator from its top bar

## 1.7.0
- The desktop app plays Color Edit, Video or Key out of a Blackmagic DeckLink as NTSC, following SECOND SCREEN. The browser version doesn't have this.

## 1.6.3
- Fixed a picture recalled from Image Tools vanishing when you start typing over it
- The MOUSE / TABLET switch has an AUTO setting, now the default: your pointer is the tablet over Color Edit and the mouse over Prompts
- The tablet works in Image Tools' Paint and Palette, holding a button paints a stroke, and the crosshair reaches every edge
- Flick the pointer off Color Edit to swipe the tablet: off a side opens Paint's palette, as on a real unit

## 1.6.2
- Fixed Image Tools' Zoom / Pan, which scaled vertically only

## 1.6.1
- Added uploading a frame to feed the MAXINE!'s video input
- Fixed font conversion with texture

## 1.6.0

The first public release of the MAXINE! Emulator in the browser.

- Fixed fade functionality
- Keyboard, mouse and paste
- Messages, settings and NVRAM saved in the browser between visits
- Video and Key export as a matching pair of PNGs.
